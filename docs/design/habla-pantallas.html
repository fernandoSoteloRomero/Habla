6. El sistema

Para que al programarla quede igual. Se arma con componentes de shadcn-vue (Button, Card, Progress, Dialog, Sonner) personalizados con estos tokens, y un set propio de pictogramas en SVG.

Colores base

Blanco andén #FFFFFF
Gris concreto, paneles #EEF0F2
Negro señal, texto #000000
Gris texto secundario #5B616B
Rosa mexicano, la acción #E4007C
Amarillo, "Estás aquí" #FFD100

Líneas y placas

Nivel 0, rosa #E4007C
A1, azul (también información) #0057B8
A2, verde (también correcciones) #00965E
B1, naranja #E87722

Placas: verde "así se dice", azul información, amarillo aviso importante. Nunca rojo.

Reglas

Alineado a la izquierda, como un letrero.
Una sola acción rosa por pantalla.
Números solo donde hay un orden real: los pasos de la sesión.
Esquinas: 7 a 9px pictogramas, 12px botones, 14px paneles.
Sin sombras, sin degradados, sin emojis.
Una sola animación: el avance entre estaciones (se apaga si el teléfono pide menos movimiento).
Botones de 52px de alto; contraste AA en todo.
